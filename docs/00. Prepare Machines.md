# Step 1: download Debian 12 (bookworm) cloud image
  
Debian provides a pre-configured cloud image that works perfectly with cloud-init.


  SSH into Proxmox host:

```
  ssh root@192.168.1.22
```


  Download the Debian 12 cloud image:

```
cd /var/lib/vz/tempate/iso/
/# Download Debian 12 cloud image
wget https://cdimage.debian.org/cdimage/archive/12.0.0/amd64/iso-cd/debian-12.0.0-amd64-netinst.iso
/# Verify download
debian-12.0.0-amd64-netinst.iso
```

# Step 2: Create VM template

```
# Create a new VM (ID 8000, you can use any free ID)
qm create 8000 --name debian-12.0-template --memory 512 --core 1 --net0 virtio,bridge=vmbr0
# Import the cloud image to VM's disk
qm importdisk 8000 /var/lib/vz/template/iso/debian-12.0.0-amd64-netinst.iso local-lvm
# Attach the disk to the VM
qm set 8000 --scsihw virtio-scsi-pci --scsi0 local-lvm:vm-8000-disk-0
# Add Cloud-Init C-ROM drive
qm set 8000 --ide2 local-lvm:cloudinit
# Set boot from the disk
qm set 8000 --boot c --bootdisk scsi0
# Add serial console (helpful for troubleshooting)
qm set 8000 --serial0 socket --vga serial0
# Enable QEMU Guest Agent
qm set 8000 --agent enabled=1
```

# 3: Configure Cloud-Init Defaults

```
# Set default user
qm set 8000 --ciuser debian
# Set default password (we'll use SSH keys instead, but this is good to have)
qm set 8000 --cipassword $(openssl passwd -6 "debian")
# Set SSH keys (replace with public key)
# ssh-keygen -t ed25519 -C "your_email@example.com"
# Then add it to the template:
qm set 8000 --sshkeys ~/.ssh/id_ed25519.pub
# Alternatively, add your key directly:
# qm set 8000 --sshkeys "ssh-ed25519 AAAAC3Nza... your_email@example.com
# Set IP configuration to use DHCP (we'll set static IPs when we clone)
qm set 8000 --ipconfig0 ip=dhcp
```

# 4: Resize the Disk

```
qm resize 8000 scsi0 +10G
```

# 5: Convert to Template

```
qm template 8000
```
