# Step 1: download Debian 12 (bookworm) cloud image
  
Debian provides a pre-configured cloud image that works perfectly with cloud-init.


  SSH into Proxmox host:

```
  ssh root@192.168.1.22
```


  Download the Debian 12 cloud image:

```
cd /var/lib/vz/tempate/iso/
/# Download Debian 12 cloud image
wget https://cdimage.debian.org/cdimage/archive/12.0.0/amd64/iso-cd/debian-12.0.0-amd64-netinst.iso
/# Verify download
debian-12.0.0-amd64-netinst.iso
```
